使い方と仕様マニュアル

        


            
1. 画像の読み込み仕様

            
画面中央をクリック、またはファイル/フォルダをドラッグ＆ドロップして画像を読み込みます。

            
    
                
  • 対応フォーマット: JPG, PNG, GIF, WEBP, PDF, EPUB（PDFは各ページを画像として展開します。EPUBは本ツールで作成したものなど画像だけのEPUBに対応し、ページ順・目次・作品情報・綴じ方向も引き継ぎます）
    • 
                
  • ブラウザによる挙動の違い: ChromeやEdge等の「File System API」対応ブラウザでは、フォルダを直接読み書きできます。FirefoxやSafari等の非対応ブラウザでは、標準のファイル選択ダイアログが開き、保存時はZIPファイルにまとめられます。
    • 
            


            
2. 並び替えとリスト操作

            
サムネイル一覧（左側）またはファイル名リスト（右側）をドラッグ＆ドロップして並び替えます。

            
    
                
  • 複数選択: Shiftキーで範囲選択、Ctrl(MacはCmd)キーで個別選択が可能です。
    • 
                
  • 外部からの追加: PCのフォルダから直接特定の場所に画像をドロップして割り込ませることも可能です。
    • 
                
  • 並び順の復元: 出力した「並び順テキスト（.txt）」を画面にドロップすると、現在のリストをそのテキストの順番通りに自動で並び替えます（目次情報も復元されます）。
    • 
                
  • 設定の復元: 出力した「現在の設定（.json）」を画面（画像上含む）のどこにドロップしても設定が復元されます。
    • 
                
  • 見開きの泣き別れ警告: 「○○.jpg」と「○○_.jpg」のように、後ろに文字を足しただけの名前の画像をペアとみなします。見開き表示でペアが別々の見開きに分かれていると、サムネイルを緑の枠で囲んで表示します（マウスを乗せると相方のファイル名を表示）。意図的に分けている画像は、ファイル名の末尾（拡張子の前）に「_ok」を付けると判定の対象外になります（ペアの片方に付ければ、そのペアは対象外）。件数は一覧の見出しにも表示されます。単ページ表示では判定しません。
    • 
                
  • 並び替え: ファイル名一覧の右上ボタンから、改行やスペース、タブ区切りで数字や文字列を入力すると、画像ファイル名を上から読み、指定の数字や文字列が含まれる画像をブロック毎に一括で並び替えます。
    • 
            


            
3. 編集・エディット機能の仕組み

            
    
                
  • 画像エディタ: サムネイルをダブルクリックし、画像編集をクリックすると画像エディタが開きます。
    • 
                
  • 一括トリミング: 一覧から複数の画像を選択し、「一括トリミング」ボタンを押すことで、指定したサイズの中央トリミングをすべての画像に一括で適用できます。
    • 
                
  • 並び順保存: 現在のファイル名の並び順と目次情報を .txt で出力し、同時にキャッシュにも保存します。復元ボタンからいつでも呼び出せます。
    • 
                
  • 設定保存: UIの状態（表示モード、サムネイルサイズ等）やEPUBのメタデータを .json で保存します。以前のバージョンで保存した .json も読み込めます。作品名が「タイトル サブタイトル Part.N」のように既定の区切り（半角/全角スペース、_、-、・）で区切られていれば、自動で分割して入力欄に入ります（分割すると作品名が変わってしまう場合は、分割せずタイトル欄にそのまま入ります）。
    • 
                
  • 入力内容の自動保存: EPUB出力設定と連続保存画面の入力内容はブラウザに保存され、次回起動時に復元されます。ファイルIDと更新日時は巻ごとに異なるため復元せず、ファイルID欄に「前回: ○○」と前回の値を表示します。更新日時には、画面を開いた時刻を「時」単位で切り上げた値（例: 13:37 → 14:00）が自動で入ります。
    • 
                
  • 目次設定: 選択した画像にチャプター名（目次）を付与します。これはEPUB出力時に電子書籍リーダーの目次機能として動作します。
    • 
                
  • 白紙挿入: 選択した画像と「同じピクセルサイズ」の真っ白な画像をメモリ上に生成し、選択した画像の後ろに挿入します。
    • 
                
  • 削除: サムネイル一覧とファイル名リストから除外します。なお、PC上の元の画像ファイルが削除されることはありません。
    • 
            


            
4. 保存・出力の仕様

            
「出力ファイル名」に入力した文字が、各出力ファイルのベース名として使用されます。「画像サイズ調整」オプションで、出力前にサイズを揃えることができます。

            
    
                
  • 連結してPDF保存: 画像を1ページずつPDF化します。ブラウザのバックグラウンドで処理されるため、大容量でもフリーズしにくくなっています。「画像縮小率」を下げることでPDFのファイルサイズを軽量化できます。
    • 
                
  • 複製を保存: 元のファイル名を維持したまま、エディタでの編集（トリミングや回転等）を適用して複製を保存します。
    • 
                
  • 連番リネームで保存: 出力ファイル名_001.jpg のように連番を振って保存します。
    • 
                
  • 見開きを結合して連番保存: 現在の「表示モード（右開き/左開き）」に従い、隣り合う2枚の画像を1枚の横長画像に結合してから出力します。
    • 
                
  • サムネイル一覧をPDF保存: 現在画面に表示されているグリッドや見開きのレイアウトをそのまま、1枚の巨大なPDFシートとして出力します。
    • 
                
  • PDFの一括出力: 各ファイルの名前は読み込んだフォルダ名になります（フォルダ名がない場合は「出力ファイル名」）。保存先に「タイトル_サブタイトル_PDF_YYMMDD提出分」フォルダを作り、その中の「PDF」に1ページずつのPDF、「サムネイル」にサムネイル一覧PDF、「並び替え」に並び順テキストと設定(.json)を振り分けて保存します。何を出力するかはチェックボックスで選べます（既定では設定(.json)以外を出力）。「フォルダを作成する」をオフにすると、チェックした各ファイルをそのままダウンロードフォルダに保存します（従来の動作）。タイトル・サブタイトルは前回この画面で入力した値が初期値になり、日付は当日です（どちらも出力前に変更可能）。FirefoxやSafariでは同じ構成のZIPファイルになります。
    • 
                
  • EPUB形式で保存: 固定レイアウトのEPUB3形式で出力します。右開き/左開きの設定はメタデータに書き込まれ、リーダーアプリでの見開き表示に反映されます。作品名と読みは「タイトル」「サブタイトル」「Part（語・番号・桁数・後の文字）」に分けて入力します。区切りは境目ごとに選べます（①タイトルとサブタイトルの間、②Partの前、③Partの語と番号の間。例: 「Part」＋③「.」＋番号 → Part.3）。番号が空欄ならPartは付きません。組み立てた作品名は入力欄の下で確認できます。
    • 
                
  • PDFの連続一括出力: 「EPUB形式で連続保存」と同じ画面で、複数のフォルダをまとめてPDF化します。提出用フォルダ「タイトル_サブタイトル_PDF_YYMMDD提出分」を1つ作り、その中の「PDF」「サムネイル」「並び替え」に全冊分のファイルを振り分けて保存します。ファイル名は、タイトルとサブタイトルが空欄ならフォルダ名、指定した場合は一覧の順に番号を振った名前（例: タイトル_サブ_Part.3.pdf）になります。空の一覧にフォルダを追加すると、先頭のフォルダ名を区切りで分割して、提出用フォルダとファイル名の各欄に自動で入力します（分割できない名前の場合は入力しません）。綴じ方向・画像サイズ調整・縮小率・サムネイルの表示サイズはメイン画面の設定を使います。
    • 
                
  • EPUB形式で連続保存: 専用画面に複数のフォルダをまとめてドロップすると、名前順に並べて一覧表示します（行のドラッグまたは↑↓で並べ替え可能）。作品名は「タイトル」「サブタイトル」「Part」に分けて入力し、境目ごとの区切り（①②③）を選べます（読みも同様）。Part番号は開始番号から1冊ごとに増え、ファイルIDは1冊目の末尾の数字を1ずつ増やします。変更後の作品名・読み・ID・出力ファイル名を一覧で確認してから実行し、保存先フォルダを1回選ぶと全冊を書き出します。綴じ方向と画像サイズ調整はメイン画面の設定を使います。
    •
